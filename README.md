# Sneha Birthday — Candy 3D Edition ❤️

A 7-page modern birthday scrapbook built with vanilla HTML/CSS/JS. Theme: candy pink + candy blue, with a sunflower stationery page and a heart-only final page.

## Pages
1. Welcome — Happy Birthday Sneha + music start.
2. Party — CSS 3D bottle; tap the cap or shake the phone.
3. Cake — CSS 3D cake; drag the knife left → right to cut it.
4. Scratch — scratch the overlay to reveal Sneha's photo.
5. Sunflower — optimized video + Hinglish letter.
6. Photo wall — four photos + appreciation + Akshita credit.
7. Final — exact birthday message + `Yours Rachit 🫶` + hearts.

## Assets
All photos, video and music are local. Images are resized WebP files, video has WebM + MP4 fallback, and music is compressed to 112 kbps for faster loading.

## Run
Open `index.html` or use VS Code Live Server.

## GitHub Pages
Upload the contents of this folder to the repository root and enable GitHub Pages from Settings → Pages.

## Notes
- Music starts after the Start button because mobile browsers commonly block autoplay until a user gesture.
- The top-right music button plays/pauses the same continuous looping track.
- The bottle has tap + motion fallback; the cake has pointer/touch drag.
- No external JavaScript libraries are required.
